Làm thành bộ sticker Telegram
  1. Tải cả bộ ở trên rồi giải nén ra 16 file PNG.
  2. Mở Telegram, tìm @Stickers (bot chính chủ), gõ /newpack rồi đặt tên bộ.
  3. Gửi từng file PNG dạng tệp (không nén), sau mỗi file gửi một emoji hợp với sticker.
  4. Gõ /publish, bỏ qua bước chọn icon, đặt tên link — xong, gửi link cho nhau là dùng được.

Đồ in

Hai tờ A4 (ảnh PNG nét 300 dpi) — in đúng khổ A4 rồi cắt theo viền.
