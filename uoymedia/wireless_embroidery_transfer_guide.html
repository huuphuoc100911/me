Không Dây Qua Wifi

Hướng dẫn từng bước cấu hình dải mạng IP, kiểm tra kết nối mạng không dây và tải mẫu thêu .DST từ máy tính sang màn hình **Dahao A15** thông qua phần mềm **EMB DesignServer**.

Phần 1: Bảng Thông Số Cấu Hình Mạng Chuẩn

Cả máy tính và máy thêu bắt buộc phải chung dải IP (Subnet)

Thành Phần Thiết Bị Thông Số Ví Dụ (Wifi 192.168.0.x) Trạng Thái / Mô Tả Hướng Dẫn
Tên Mạng Wifi (SSID) RED THREAD T2 Cả PC và Máy thêu A15 phải bắt chung 1 điểm phát Wifi này.
IP Máy Tính (PC Server) 192.168.0.200 Kiểm tra qua lệnh ipconfig trên PC (dải mạng hiện tại).
IP Máy Thêu A15 (Dòng C43) 192.168.0.213 Nhập đúng địa chỉ IP thực tế do Wifi cấp cho A15 vào dòng **C43**.
IP Máy Chủ / Server (Dòng C44) 192.168.0.200 Điền chính xác địa chỉ IP của Máy tính vào dòng **C44** trên A15.
Mặt Nạ Mạng / Subnet Mask (C45) 255.255.255.0 Lớp mặt nạ mạng con tiêu chuẩn mặc định.
Cổng Mạng / Gateway (C46) 192.168.0.1 Địa chỉ Gateway của Router Wifi mới (Trang 3/4 cài đặt A15).
Cổng Máy Chủ / Port (C41) 3865 Cổng giao tiếp mặc định của phần mềm Dahao EMB DesignServer.

Phần 2: Quy Trình Cấu Hình Trên Màn Hình A15

Các thao tác điều chỉnh cài đặt mạng trực tiếp trên máy thêu

BƯỚC 01

Bắt Sóng Wifi Mới

Nhấn vào biểu tượng **Wifi (có dấu X)** ở góc trên màn hình A15. Chọn tên Wifi mới (ví dụ: RED THREAD T2), nhập mật khẩu và ấn **Tích xanh**.

Ghi nhớ số 192.168.0.xxx xuất hiện ở dòng chữ "IP mạng không dây" trên cùng.
BƯỚC 02

Sửa C43 & C44 (Trang 2/4)

Vào menu Cài đặt tham số mạng.
• Dòng **7 (C44)**: Nhập IP máy tính 192.168.0.200.
• Dòng **9 (C43)**: Nhập IP thực tế vừa nhận 192.168.0.213.

Đảm bảo chọn biểu tượng Cây Bút và bấm **Lưu** sau mỗi dòng.
BƯỚC 03

Chỉnh C46 & Khóa IP (Trang 3/4)

Chuyển sang trang 3/4:
• Dòng **1 (C46)**: Đổi Gateway thành 192.168.0.1.
• Dòng **3 (Z03 - DHCP)**: Bật sang **OFF** để khóa không cho đổi IP tự động.

Nếu bị đứt mạng, hãy tắt công tắc nguồn A15 khoảng 10s rồi bật lại.

Phần 4: Quy Trình 4 Bước Upload Mẫu Thêu

Các thao tác gửi file từ máy tính sang màn hình A15

01
Thao tác trên PC

Khởi Chạy Quyền Administrator

Nhấp chuột phải vào biểu tượng ứng dụng EMB DESIGNSERVER trên Desktop -> Chọn Run as administrator.

Biểu tượng máy thêu CN: 1115 (hoặc IP) sẽ hiện sáng màu xanh lá trong giao diện.
02
Thao tác trên PC

Chọn Mẫu Thêu Từ Ổ Đĩa (Send From Disk)

Bấm vào nút Send From Disk trên thanh công cụ phần mềm. Duyệt thư mục lưu trữ mẫu thêu trên máy tính và chọn file thiết kế (định dạng .DST, .DSB).

03
Thao tác trên PC

Phát Lệnh Gửi File Sang Máy Thêu

Nhấp chọn khung máy thêu đích CN: 1115 màu xanh lá -> Bấm nút Send / Truyền. File sẽ được đẩy trực tiếp qua Wifi nội bộ sang máy thêu.

04
Thao tác trên A15

Lưu File Vào Bộ Nhớ A15 & Chạy Thêu

Trên màn hình A15: Vào mục Bộ nhớ / Mẫu thêu -> Nhấn nút Nhận mẫu từ Mạng (Network/Server). Chọn tên file vừa truyền từ PC và nhấn Lưu để chuẩn bị canh khung & chạy thêu.
